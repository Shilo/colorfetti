Renderer CPU is not worker CPU. The separate worker-resource run supplies actual RPC spans/transfer counts and GC-backed memory observations, correctly excluding them from CPU or peak-memory claims. Warm-process new documents are not process-cold. Paired differences of marginal medians need not equal the median paired difference; the recomputation retains both. No pair is discarded to improve the verdict.

Full-palette native outputs use an independent scalar matcher and independent decoder. Source hashes, counter writes and canvas readback are not substituted for exact output witnesses.

Actual Codex Browser current-baseline workflows and native historical A/Bs are separate surfaces. Auxiliary sandboxed Edge core/editor probes do not become Codex Browser results.
