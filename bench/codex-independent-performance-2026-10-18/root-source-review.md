## Coordinator primary-source decisions, freshly consulted October18

- [Svelte effects](https://svelte.dev/docs/svelte/$effect) and [derived values](https://svelte.dev/docs/svelte/$derived): synchronous reads determine dependencies; effect cleanup runs on rerun/unmount. Applied to Tile metadata, captured preview requests, Dock observers and App queue pruning. Keep untracked presentation reads outside conversion invalidation. `tick` settles DOM, not all async source work. Supported by installed Svelte5; no dependency change.
- [Chrome layout guidance](https://web.dev/articles/avoid-large-complex-layouts-and-layout-thrashing): geometry after style writes can force layout. Applies to workspace packing and CanvasGrid/editor. Infer a possible cost, then measure actual reads/style/layout time. Generic read-first advice is unsafe if second geometry intentionally depends on updated grid placement. No unsupported containment/layout change assumed.
- [Long Tasks](https://developer.mozilla.org/en-US/docs/Web/API/PerformanceLongTaskTiming) and [Long Animation Frames](https://developer.mozilla.org/en-US/docs/Web/API/Performance_API/Long_animation_frame_timing): observations have support/threshold limits. Test probe detects entry types, uses finite rAF windows and records forced-style/layout attribution where available. No tasks observed>=50ms is weaker than uninterrupted smoothness; main-thread entries omit worker CPU. Actual Codex API lacks process restart/CDP worker trace, explicitly qualified in surface evidence.

Further fresh primary-source call-site decisions and browser fallback tradeoffs are in `core/api-research.md`, `io-android/api-research.md`, `ui-tooling/api-research.md`; these were independently gathered by the assigned reviewers.
