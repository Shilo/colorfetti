# Independent caption-drag boundary challenge

Reviewed current Tile's original/1-bit usage effects and Dock's drag wiring in addition to the assigned gesture implementation. This is fresh source reasoning; device timings/correctness outputs are coordinator/native-agent responsibilities, not inherited receipts.

`sliderDrag.press()` records a pointer but does not report dragging. The first actual Style input writes `own[key]` and calls move; only then does the shared report set dragging. Dock passes Svelte `tick` for redrawn, so its150ms rest begins after the current reactive flush rather than before conversion. A simple pointer press without movement should therefore leave caption scheduling unchanged. change/up/cancel/blur call end. Dock's effect calls end when panel/style/tray/chip removal detaches its control, and returns end for teardown.

Tile's 1-bit effect tracks captured item, inks, style/settings, family, analysis pending, active/budget and tiny metadata revision. It first retains at most one prior result only when `previous.original === current.original`, marks it pending, and returns without collection while analysis is pending, surface inactive or drag budget positive. This covers exact-size tiles too; the current spec says captions remain pending through a Style drag, so the broader deferral is not itself a defect. Rest/release sets budget0, reruns the effect and uses the current captured settings. Metadata publication during a drag can rerun the cheap effect but does not start full inspection until budget0.

The old effect's returned controller aborts before rerun/destroy; completion checks its own signal before publishing. There is no new converted buffer or chained retained usage record in this path. Earlier work can finish its current synchronous mask before cancellation is observed, so absence of a stale publication does not imply zero obsolete CPU. A pause then resumed drag must abort newly resumed inspection through the same effect cleanup.

Original usage has its own item-owned collection/controller and state; the drag-budget gate does not suppress source RGB metadata. Original captions must read that separate result rather than borrow the retained converted count. Viewer Tile's default budget0 and independent surface ownership permit its own count work; closing it must not cancel an independent wall subscriber. The coordinator/core reviewer owns queue internals and exact count-oracle review.
