## Independent opportunity ranking and falsifiers

1. **CanvasGrid irrelevant structure→measure/root writes.** Actual redundant path is visible in source. Count observer callbacks, spacing sorts, same-value writes, forced style/layout in import1/2/4/8, ten preset steps, editor review/paging and first-tile replacement. Candidate only if measurable practical CPU/input reduction without checker movement. Double-rAF coalescing may make savings too small; no ship based on call counts alone.
2. **Editor mount/layout attribution.** Compare real64-button/canvas/tooltip page against diagnostic no-op tooltip action, then separately deep versus raw arrays, keeping identical DOM and native modality. Include256 colors and4096 recovery. Hidden tip removal cannot discard initial accessible description. If script share is tiny versus style/layout, do not misattribute native editor stall to proxies/listeners.
3. **Viewer checker repaint and repeated dialog BCR.** Native pan/zoom at DPR, attribute paint/raster/layout and getBCR count. Separate immediate transform cost from delayed sampled refinement. A translated checker layer must preserve subpixel phase, bounds and memory; a geometry cache must invalidate visual viewport/resize/modal placement. No polling or stale-frame shortcut.
4. **Paint-only palette action resets.** Fresh source-derived lead: drawSwatch/drawPair/drawPreview unconditionally resize fixed-dimension canvas on action update. Instrument updates during unrelated UI state, label changes, selection and 1-bit ink drags. If repeated identical updates are not frequent or cost negligible, reject. A dimension/equality guard must still clear empty and retain invalid-input atomicity; this is not demonstrated yet.
5. **Style thumbnail preparation.** Fresh source-derived lead: stylePreview creates new analysis for its tiny fixture each call and can repeat structural preparation. Check Dock dependencies and open list settings/color updates. Bound savings versus memoization retained state; do not cache dynamic full artwork or change style examples.
6. **Gesture tiny allocations.** Pointer sample spreads a small Map and reads dialog geometry per input. Likely negligible; use traces before any pooling/cache complication. Existing no-op publish guard already avoids broad reactive churn.
7. **Export ready-file reuse.** Only if explicit Save frequently follows a ready identical hover export and fresh output equivalence/lifetime proof shows duplicated encoding. Current ready and grace records have deliberate source ownership; no blanket retained cache.
8. **CSS/dependency/build changes.** No demonstrated safe runtime improvement from selector consolidation, blur removal, icon rewrite, worker render rewrite or dependency upgrades. Preserve visual/accessibility contracts and keep build-only work distinct from main-thread interaction.

This ranking was formed from source before the UI timing runs. Subsequent bounded outcomes: the editor's four auxiliary variants and the exclusive controller's native both-off falsifier failed their materiality/reliability gates (editor-attribution-decision.md); fresh CanvasGrid counters reproduced redundant work without establishing a material saving (grid-counter-decision.md). Paint-only action resets were counted, but not accepted as an optimization. The remaining viewer/thumbnail/export leads have no demonstrated safe gain from this reviewer. No runtime UI candidate was accepted. Tooling discovery is the only live checkout edit made by this reviewer.
