The chosen design preserves overview sampling and adds explicit sampled/full-source raster status. Inspect pixels pauses one selected animation frame and renders every source pixel. Previous/Next and a frame number field select a paused frame; returning to overview resumes playback. Source-coordinate dithering, alpha, full analysis, whole-item palette selection and whole-clip Cleanup remain unchanged. Copy still encodes the first frame; Save still exports the whole animation. Their GIF tooltips explain this scope.

Inspection admits at most 4,194,304 pixels and 16,384 pixels per axis. Larger images retain overview with a clear explanation and Save guidance. Native mode initially zooms to one source pixel per CSS pixel, constrained by the existing minimum zoom for tiny sprites. DPR can paint multiple physical pixels per CSS pixel; full-source raster status does not promise a physical-pixel mapping at every zoom. Native mode permits additional zoom levels for long sheets without extending overview's 16× maximum.

One active native conversion and one latest pending request are allowed across all viewer instances through a module-shared queue. Cancelled work cannot publish; later work waits for actual active settlement even after a dialog closes and another opens. Native preparation also waits for actual superseded ordinary producers, including shared work started by another Tile. Every cache subscriber receives the real producer settlement; an aborted subscriber promise cannot open the barrier early. The native path bypasses animation raster caches and clears the previous displayed native frame before preparing the next. It borrows immutable original/analysis arrays and clones only the analysis container and mutable icons map. New structural preparations are local to the job rather than cached across every inspected source frame.

Viewer lifetime, native jobs and ordinary conversion consumers hold optional artwork admission leases. A cache producer separately acquires a lease synchronously and releases it only when its actual producer promise settles; subscriber cancellation alone cannot free source accounting while shared work still owns the pixels. The last-subscriber-abort regression covers this distinction.

The final ownership follow-up projects queued Palette work to its selected original and resolved Cleanup result/apply only. Ordinary preview/report records carry opaque item/frame identities and a scalar frame count; completed native display records carry only pixels and an opaque request key. Legacy native work synchronously charges its one captured selected analysis at 3 bytes/pixel plus 2 KiB in M1's separate 128 MiB captured-analysis ledger and releases that charge only after actual queue settlement. Budget failure offers wait/overview/retry guidance before enqueueing. Palette work does not capture obsolete legacy analysis.

The logical native headroom is 84 MiB, statically bounded by the 4 MP cap and shared queue. It is separate from the 256 MiB source ledger; artwork admission does not charge an 84 MiB reservation token. The worst audited cold Icon path allocates 15 bytes/source pixel for preparation plus one byte/pixel for its mask. Allowing another 4 bytes/pixel for a prior canvas gives 80 MiB at the 4 MP limit, with 4 MiB for dimension, glyph, palette and job metadata. This is not a process heap, garbage collection or GPU memory guarantee. Existing source/analysis and pre-existing source-owned structural caches belong to separate accounting. Native legacy masks remain synchronous once started; cancellation is authoritative before and after that call but cannot interrupt it midway.

`native-cost.mjs` measures Node CPU and array-buffer deltas for the 2048² Palette/Keep/dither, cold Stencil and cold Icon paths. These are diagnostic timings, not browser latency or peak-memory promises.

`export-parity.mjs` compares production native output with independently Sharp-decoded production Save output. Its 18 cases include 2048² Palette, cold Stencil/Icon with None, a 16,384×8 long sheet, twelve RGB/Oklab × Cut/Keep × strength 0/50/100 partial-alpha cases with Max 3 and Cleanup, and selected frames 0/7/19 of a 20-frame 1024² GIF using whole-clip Max 2 and Cleanup. All visible RGB and every alpha byte match. Transparent RGB is ignored because legacy PNG intentionally stores an ink RGB under transparency. The fixture generator and oracle version are recorded beside the results.
