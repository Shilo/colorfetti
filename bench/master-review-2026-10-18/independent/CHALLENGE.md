## Cross-check of root export/Stencil probes

`root/crop-probe.mjs` and `root/crop-results.json` support six current-writer/cropped comparisons with exact visible RGB, every alpha byte, canvas/frame/delay/loop metadata. Four historical-workload reconstructions save43.5–65.8%; two constructed empty/edge cases save23.9–25.3%. Those ranges describe different cases and should stay separate. The script exercises `encodePaletteGif`, not the legacy encoder; both-family integration remains an acceptance requirement. Historical input length matches reconstruction length, but this script alone does not assert encoded byte equality with historical input. Do not describe length equality as byte equality without another guard.

`root/io-stencil-probe.mjs` correctly isolates sharedAuto80/80, spriteAuto80/80 and spriteMedian180/20 while all64 unchanged subject pixels flip: simply unifying thresholds cannot solve this witness, and changing its median protection could violate the fewer-than-half-interior rule. Its ANIMEXTS source/export independent loop result supports actual metadata loss. Missing EOI and out-of-screen patch probes establish strict rejection versus Sharp acceptance, not a fully defined or safe recovery policy; notably Sharp reports width2 for the out-of-screen patch whose logical width was patched to1, so it does not establish clipping-to-logical-screen behavior. Its PNG compaction comparison changes bit depth, palette/chunks and sRGB presence together; report exact fixture savings only as a combined-encoder prototype.

## Priorities from this scope

Implement light-theme enabled-text contrast as a small demonstrated fix. Include trustworthy native output inspection in the high-value work. Copy corrections are useful low-effort follow-ups. Keep candidate8/Knoll, direct-map performance claims, vertical wheel remapping, dirty-draft prompts, Undo, shortcuts and upscale out of 'proven simple fixes'; each has the decision/acceptance limits above. Remove blanket endorsements of exact codecs/color profiles and universal no-benefit assertions for all tone/noise/matching alternatives; bounded tests support only the tested settings and sources.
