## Round one: premeasurement/source review

The frozen 2048-sheet CPU profile supplies real attribution: nearest `convert` (`Fa`) accounts for approximately 59.223 ms weighted self samples during Save against 111.647 ms renderer TaskDuration. PNG packing is approximately 8.779 ms; preview `colorize` is not an export hot spot in that trace. The profile is exploratory, not proof the addressing subexpression alone costs 59 ms or that the candidate improves it. Reproduction/aggregation: `node bench/whole-app-performance-2026-10-17/review/profile-review.mjs`.

For ordinary source dimensions, both axis maps are identity when `mw === w && mh === h`, so `p = o * 4` addresses exactly the same source pixel. Both comparisons are essential: preserving only width or height does not establish a linear map. Number multiplication preserves offsets without 32-bit truncation. The patch changes no matching arithmetic, order/ties, alpha eligibility, used flags, dither coordinates or cancellation checks. It adds one Boolean to a short-lived job and a branch per nearest pixel; tiny/sampled and high-entropy cases therefore still require regression measurements.

Concrete correction requested before timing: bound this optimization predicate to `w <= 0x80000000 && h <= 0x80000000`, preserving the original Int32 maps for unusual larger accepted array-like callers. Do not add a new input rejection. No practical browser-decoded fixture can exercise such dimensions, so no enormous allocation test is required.

Predeclared gates are recorded by the implementer in `desktop/candidate-full-source.md`: 15% median target kernel and 10% integrated Save renderer benefit, five alternating warmed pairs, all adverse trials, no new >50 ms stall, common/adverse regression threshold >5% and >3 ms with uncertainty considered. Native evidence remains necessary after a desktop pass. A correct scalar shortcut alone does not satisfy those gates.

Coverage includes odd rectangles, 1px axes, full source, either axis sampled separately, palettes 1/2/4/16/64/256, both metrics, Cut/Keep and cut1/128/255, dither zero/nonzero parity, sync/async and cancellation. Execution/results pending the reserved host window. Dither differential parity is explicitly not an independent dither algorithm proof.
